# BA work management
Read WORKSPACE_RULES.md and BA_RULES.md on demand. Locate existing work-item files in project-workspace/work/. Maintain owner, status, priority, dependency and source in their current files/format. Never require a backlog subdirectory, new Epic index, renames or migration. If a new file is necessary and approved, create it directly in work/. Preserve human approvals as externally evidenced.
