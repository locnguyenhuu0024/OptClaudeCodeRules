# Test Automation Source

This is the ONLY managed project location for runnable test scripts, fixtures, helpers and test configuration. Put E2E in e2e/, API in api/, integration in integration/, fixtures in fixtures/ and helpers in helpers/. Link scripts by shared TC ID to project-workspace/work/features/<FEAT-ID>/qa/automation/test-mapping.md. Store runner outputs under ignored local subdirectories here (e.g. .artifacts/) and sanitized reports in work/. No product application code or global dependency editing.
